# 🗳️ מערכת בחירות לתלמידים

- **אתר תלמידים** (`/`) – כל תלמיד נכנס עם קוד אישי, בוחר מועמד ומצביע פעם אחת.
- **דשבורד מורים** (`/admin`) – גרף קולות חי, ניהול מועמדים (שם + תמונה, מתעדכן מיד באתר התלמידים), יצירת קודים לתלמידים, פתיחה/סגירה של ההצבעה.
- **PDF להורים** – כפתור "הורדת דוח PDF להורים" עם תוצאות, גרף ואחוז הצבעה.
- **PDF פתקי קודים** – 12 פתקים בעמוד, להדפסה וחיתוך, כל תלמיד מקבל פתק.

## איך מזהים תלמידים
המורה מדביק רשימה (`שם, כיתה` בכל שורה, אפשר מאקסל). המערכת יוצרת לכל תלמיד קוד ייחודי בן 6 תווים.
הקוד עובד פעם אחת בלבד (הבדיקה אטומית, גם לחיצות מקבילות לא יספרו פעמיים).
**ההצבעה חשאית:** נשמר רק "הקוד X כבר הצביע" ובנפרד "מועמד Y קיבל קול", בלי קישור ביניהם.

## העלאה לענן (Netlify – חינם, ~3 דקות)
האתר משתמש ב-Netlify Functions + Netlify Blobs לשמירת הקולות, בלי להקים מסד נתונים.

1. היכנסו ל-https://app.netlify.com → **Add new site → Import an existing project → GitHub** ובחרו את הריפו הזה (ואת הבראנץ' עם הקוד).
2. הגדרות בנייה: להשאיר ברירת מחדל (הכול כבר ב-`netlify.toml`). לחצו **Deploy**.
3. **חשוב:** Site configuration → Environment variables → הוסיפו `ADMIN_PASSWORD` עם סיסמה למורים, ואז Deploys → Trigger deploy.
4. הקישורים:
   - תלמידים: `https://<שם-האתר>.netlify.app/`
   - מורים: `https://<שם-האתר>.netlify.app/admin`

> Vercel / GitHub Pages: האתר דורש שרת לשמירת הקולות, ולכן GitHub Pages (סטטי בלבד) לא מתאים.
> ב-Vercel צריך להחליף את שכבת האחסון (`netlify/functions/api.mjs`) ל-Vercel KV/Upstash; הליבה ב-`lib/api.mjs` לא תלויה באחסון.

## הרצה מקומית
```bash
npm install
npm run dev        # http://localhost:8888  (מורים: /admin, סיסמה ברירת מחדל admin123)
npm test           # בדיקות API
```

## אבטחה – חשוב לדעת
- בלי `ADMIN_PASSWORD` הסיסמה היא `admin123` (הדשבורד מציג אזהרה).
- קודי התלמידים נשמרים בשרת ונראים למורה בדשבורד – זה המנגנון לזיהוי תלמידים.
- התמונות מוקטנות בדפדפן ל-480px ונשמרות יחד עם המועמד.
