# 🗳️ מערכת בחירות לתלמידים (ירוק-לבן)

- **אתר תלמידים** (`/`) – התלמיד מקליד שם פרטי ושם משפחה, בוחר מועמד ומצביע פעם אחת.
- **דשבורד מורים** (`/admin`) – גרף קולות חי, הוספת מועמדים (שם + תמונה, מתעדכן מיד באתר התלמידים), רשימת מי הצביע, פתיחה/סגירה של ההצבעה.
- **PDF להורים** – כפתור "הורדת דוח PDF להורים" עם תוצאות וגרף.

## איך זה עובד
המורים מוסיפים רק את **המועמדים**. אין רשימת תלמידים וקודים.
כל תלמיד מקליד את שמו, והמערכת בודקת כפילויות:
- לא משנה סדר השמות ("דנה כהן" = "כהן דנה"), רווחים מיותרים, מקפים, ניקוד או אותיות גדולות/קטנות.
- חובה שם פרטי ושם משפחה (כדי להקטין התנגשויות בין תלמידים).
- הבדיקה אטומית, גם לחיצות מקבילות לא יספרו פעמיים.
- גם מועמדים לא יכולים להיות כפולים.

**ההצבעה חשאית:** נשמר רק "השם X כבר הצביע" ובנפרד "מועמד Y קיבל קול", בלי קישור ביניהם.

**מגבלה:** זיהוי לפי שם בלבד לא מונע מתלמיד להקליד שם של חבר שעוד לא הצביע, ושני תלמידים עם אותו שם מלא יחסמו זה את זה.
המורה רואה בלשונית "מי הצביע" את כל השמות, ויכול ללחוץ "שחרור" כדי לאפשר לתלמיד להצביע שוב (הקול שנספר נשאר).

## העלאה לענן (Netlify – חינם, ~3 דקות)
האתר משתמש ב-Netlify Functions + Netlify Blobs לשמירת הקולות, בלי להקים מסד נתונים.

1. היכנסו ל-https://app.netlify.com → **Add new site → Import an existing project → GitHub** ובחרו את הריפו הזה (ואת הבראנץ' עם הקוד).
2. הגדרות בנייה: להשאיר ברירת מחדל (הכול כבר ב-`netlify.toml`). לחצו **Deploy**.
3. **חשוב:** Site configuration → Environment variables → הוסיפו `ADMIN_PASSWORD` עם סיסמה למורים, ואז Deploys → Trigger deploy.
4. הקישורים:
   - תלמידים: `https://<שם-האתר>.netlify.app/`
   - מורים: `https://<שם-האתר>.netlify.app/admin`

> Vercel / GitHub Pages: האתר דורש שרת לשמירת הקולות, ולכן GitHub Pages (סטטי בלבד) לא מתאים.
> ב-Vercel צריך להחליף את שכבת האחסון (`netlify/functions/api.mjs`) ל-Vercel KV/Upstash; הליבה ב-`lib/api.mjs` לא תלויה באחסון.

## הרצה מקומית
```bash
npm install
npm run dev        # http://localhost:8888  (מורים: /admin, סיסמה ברירת מחדל admin123)
npm test           # בדיקות API (כולל כפילויות)
```

## אבטחה – חשוב לדעת
- בלי `ADMIN_PASSWORD` הסיסמה היא `admin123` (הדשבורד מציג אזהרה).
- השמות של מי שהצביעו נשמרים בשרת ונראים למורה בדשבורד (בלי המועמד שנבחר).
- התמונות מוקטנות בדפדפן ל-480px ונשמרות יחד עם המועמד.
