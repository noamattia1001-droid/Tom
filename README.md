# 🗳️ תום כפר נוער – מערכת בחירות לתלמידים

- **אתר תלמידים** (`/`) – התלמיד מקליד את תעודת הזהות שלו, בוחר מועמד ומצביע פעם אחת.
- **דשבורד מורים** (`/admin`) – גרף קולות חי, הוספת מועמדים (שם + תמונה, מתעדכן מיד באתר התלמידים), רשימת מי הצביע, פתיחה/סגירה של ההצבעה.
- **PDF להורים** – כפתור "הורדת דוח PDF להורים" עם תוצאות וגרף.

## איך זה עובד
1. **המורים** נכנסים ל-`/admin` ובלשונית **מצביעים** מוסיפים כל תלמיד שמותר לו להצביע: שם + תעודת זהות (אחד אחד, או הדבקת רשימה מאקסל).
2. **התלמיד** נכנס לאתר, מקליד את תעודת הזהות שלו, בוחר מועמד ומצביע פעם אחת.

**בדיקות:**
- תעודת זהות שאינה ברשימה לא יכולה להצביע.
- ספרת הביקורת נבדקת בהוספה (תופס טעויות הקלדה), ותעודת זהות כפולה נדחית.
- הבדיקה אטומית: גם לחיצות מקבילות או כתיבה שונה של אותו מספר (`100-000-074`) לא יספרו פעמיים.
- הגבלת ניחושים: אחרי 40 כשלונות ב-10 דקות מאותו IP, הכניסה נחסמת זמנית.
- גם מועמדים לא יכולים להיות כפולים.

**פרטיות:**
- תעודות הזהות לא נשמרות בגלוי: רק צופן (HMAC עם מפתח אקראי), ובדשבורד מוצגות 3 ספרות אחרונות.
- אתר התלמידים לא חושף שם של אף תלמיד.
- ההצבעה חשאית: נשמר רק "הצביע" ובנפרד "מועמד Y קיבל קול", בלי קישור ביניהם.
- תעודת זהות היא מידע אישי רגיש, במיוחד של קטינים. מומלץ לוודא מול ההנהלה/ההורים שמותר לאסוף אותה למטרה הזאת.

**מגבלה:** מי שיודע תעודת זהות של חבר שעוד לא הצביע יכול להצביע במקומו. ההגנה היחידה היא שהמספר לא ידוע לאחרים.

## העלאה לענן (Netlify – חינם, ~3 דקות)
האתר משתמש ב-Netlify Functions + Netlify Blobs לשמירת הקולות, בלי להקים מסד נתונים.

1. היכנסו ל-https://app.netlify.com → **Add new site → Import an existing project → GitHub** ובחרו את הריפו הזה (ואת הבראנץ' עם הקוד).
2. הגדרות בנייה: להשאיר ברירת מחדל (הכול כבר ב-`netlify.toml`). לחצו **Deploy**.
3. **שם האתר:** Site configuration → Change site name → `tom-kfar-noar` (אם תפוס, אפשר `tom-kfar-noar-elections`).
4. **חשוב:** Site configuration → Environment variables → הוסיפו `ADMIN_PASSWORD` עם סיסמה למורים, ואז Deploys → Trigger deploy.
5. הקישורים:
   - תלמידים: `https://tom-kfar-noar.netlify.app/`
   - מורים: `https://tom-kfar-noar.netlify.app/admin`

> Vercel / GitHub Pages: האתר דורש שרת לשמירת הקולות, ולכן GitHub Pages (סטטי בלבד) לא מתאים.
> ב-Vercel צריך להחליף את שכבת האחסון (`netlify/functions/api.mjs`) ל-Vercel KV/Upstash; הליבה ב-`lib/api.mjs` לא תלויה באחסון.

## הרצה מקומית
```bash
npm install
npm run dev        # http://localhost:8888  (מורים: /admin, סיסמה ברירת מחדל admin123)
npm test           # בדיקות API (כולל תעודות זהות וכפילויות)
```

## אבטחה – חשוב לדעת
- בלי `ADMIN_PASSWORD` הסיסמה היא `admin123` (הדשבורד מציג אזהרה).
- רשימת המצביעים (שמות + 3 ספרות אחרונות) נשמרת בשרת ונראית למורה בדשבורד, בלי המועמד שנבחר.
- התמונות מוקטנות בדפדפן ל-480px ונשמרות יחד עם המועמד.
